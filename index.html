M.Sc. thesis research

Imitation Learning of Skills by a Humanoid Robot and Improving Its Performance with Vision Transformers

IUT, 2022 - 2026 | Supervisor: Dr. Maziar Palhang | Methodology and documentation

  • Built a Webots pipeline to train a simulated NAO robot on greeting and surface-wiping tasks, with separate visual representation learning and policy training stages.
  • Trained ViT-B/16 and fine-tuned EfficientNetV2-S using time-contrastive triplet loss and hard-negative mining. Used cosine similarity between embeddings as a dense imitation reward.
  • Evaluated representations with GroupKFold and inspected embeddings with PCA, t-SNE, and UMAP. ViT-B/16 showed clearer temporal separation; the imitation policy converged in simulation.

The repository provides a methodology overview. Source code is not public because of institutional intellectual property restrictions.

Selected research projects

Independent projects. Status labels distinguish evaluation code and ongoing work from completed experiments.

8 projects shown

Hallucination probing on HALP-Bench

Repository

Evaluation ongoing. Probes visual features and vision- and query-token states for hallucination risk before answer generation. The protocol uses image-grouped splits, multiple models and seeds, calibration analysis, and bootstrap intervals.

CLIP uncertainty: selective prediction and OOD detection

Repository

Evaluation code; five-seed protocol. Compares softmax confidence, prompt agreement, and conformal set size with frozen zero-shot CLIP. Tests use CIFAR-10, CIFAR-10-C, and CIFAR-100 and SVHN as OOD inputs, with risk-coverage curves, AURC, calibration, OOD metrics, and bootstrap intervals.

CLIP conformal prediction under visual and prompt shift

Repository

Evaluation code; five-seed protocol. Compares APS, temperature-scaled APS, and RAPS with frozen zero-shot CLIP on CIFAR-10 and CIFAR-10-C. The pipeline measures empirical coverage and set size with clean, corruption-matched, and prompt-matched calibration.

ChartQAPro: evidence-first chart question answering

Repository

Prototype; evaluation ongoing. Compares direct prompting with a two-stage pipeline that extracts chart evidence before answering. The benchmark has no ground-truth evidence annotations, so answer accuracy alone cannot establish evidence faithfulness.

Industrial anomaly detection under shift: VisA PCB1

Repository

Evaluation code. Compares frozen ResNet-50 and DINOv2 embeddings using k-nearest-neighbor anomaly scores and post-hoc calibration under controlled corruptions. The pipeline measures AUROC, AUPRC, adaptive ECE, Brier score, and AURC, and supports false-positive and false-negative analysis.

SUIM segmentation and uncertainty

Repository

Evaluation code implemented. Combines DeepLabV3 with a MobileNetV3-Large backbone, Monte Carlo Dropout, and temperature scaling in PyTorch. The pipeline measures mIoU, Dice, pixel entropy, and calibration on local SUIM splits.

Pose-based fall detection

Repository

Benchmarking ongoing. Uses frozen YOLO11n-Pose to extract 17-keypoint sequences. The classifier combines joint-motion features, skeleton graphs, temporal convolutions, and attention; benchmark runs and cross-dataset comparisons are in progress.

DeepWeeds image classification

Repository

Completed single-seed comparison. Compared EfficientNet-B0, MobileNetV3-Large, and ViT-Tiny on eight weed species and a background class using a leakage-audited 60/20/20 train/validation/test split. In this run, MobileNetV3-Large led in top-1 accuracy (84.02%), ViT-Tiny in macro F1 (80.32%), and EfficientNet-B0 in macro recall (88.01%).
